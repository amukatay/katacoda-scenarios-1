## Использование блока с подсказками
SberCode может прятать текст с подсказкой в блок:
<hint-block title="Нажмите, чтобы увидеть подсказку" text="Здесь вы можете подсказать решение какой-нибудь задачи. Учтите, что блок с подсказкой не поддерживает форматирование текста"/>


Markdown для вставки блока с подсказками:

<pre>
<hint-block title="Нажмите, чтобы увидеть подсказку" text="Здесь вы можете подсказать решение какой-нибудь задачи. Учтите, что блок с подсказкой не поддерживает форматирование текста"/>
</pre>

## Использование расширенного блока с подсказками
Вы можете использовать расширенный блок с подсказками с поддержкой Markdown внутри блока:
<details>
<summary>Подсказка</summary>

В подсказке поддерживается Markdown, в том числе и его расширение.
Например, вот **жирный текст**.
  
<details>
<summary>Подсказка внутри</summary>

Это подсказка внутри подсказки. Ниже кнопка открытия файла.
`file2.txt`{{open}}

</details>

</details>

Markdown для расширенного блока:
<pre>
<details>
<summary>Подсказка</summary>

В подсказке поддерживается Markdown, в том числе и его расширение.
Например, вот **жирный текст**.
  
<details>
<summary>Подсказка внутри</summary>

Это подсказка внутри подсказки. Ниже кнопка открытия файла.
`file2.txt`{{open}}
</details>

</details>
</pre>

## Поддержка тестов для самопроверки
Пример простого теста:

<self-test title="Заголовок теста">
q: Вопрос 1. Выберите верный ответ.
+ ответ 1 верный
- ответ 2 неверный
- ответ 3 неверный
q: Сколько будет 2+2*2?
- 4
+ 6
+ 8
- 10
- 12
</self-test>

Markdown для вставки теста:
<pre>
<self-test title="Заголовок теста">
q: Вопрос 1. Выберите верный ответ.
+ ответ 1 верный

- ответ 3 неверный

- 4

- 12
</self-test>
</pre>

## Вставка кнопки на опросник
SberCode может вставлять кнопку с сервиса опросов public.oprosso.sberbank.ru:
<oprosso link="/p/123" text="Пройдите опрос"/>

Markdown для вставки опроса:
<pre>
<oprosso link="/p/123" text="Пройдите опрос"/>
</pre>
